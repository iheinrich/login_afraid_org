Login to afraid.org Dynamic DNS v2 without a browser.

### Installation and use
:sparkles: Clone or download source code then execute ```bash dev/setup.sh``` to install build environment. Setup requires Python >= 3.9 and will recommend follow up actions after installation.<br>
:recycle: A standalone executable for your system[^1] can be built after setup. If you're only interested in the standalone executable you can remove the source code folder after build. Or, if you are using Linux on a x64 CPU, you can [download the v1.1.0 binary](https://github.com/iheinrich/login_afraid_org/releases/download/v1.1.0/login_afraid_org).

[^1]: <small>Linux is tested and works for current Debian/Ubuntu. Windows and Mac should also work but are untested. Binaries for a specific OS can be created *on* that OS only, no cross-build.</small>

### Development
:see_no_evil: The current version *works for me*<sup>:tm:</sup> on Debian. If afraid.org should ever change their page the code will probably be adapted.<br>
:loudspeaker: If you notice it stopped working, or if it doesn't work for you, please [open a new issue](https://github.com/iheinrich/login_afraid_org/issues/new). I'll do my best to get to it as soon as possible.
